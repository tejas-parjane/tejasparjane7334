## Repository conventions

- Default branch is `main`
- Public repositories carry an Apache-2.0 license
- Active Python projects ship tests and a CI workflow
- Finished or superseded projects are archived so the profile stays focused
- Secrets stay out of git — `.env` is ignored and `.env.example` documents what is required
